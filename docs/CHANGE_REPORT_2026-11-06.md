# 2026-11-06 變更整理

## 繪圖與幾何

- 新增圓弧工具，置於繪圖工具列末端；使用共用物件類型登錄表、圖示及選項模型。
- 圓弧依「圓心 → 半徑與起始角 → 結束角」放置；也可由圓心拖出半徑與起始角，再確認結束角。支援即時預覽、取消、圓心吸附、端點拖曳、單步復原與 SVG 歸檔。
- 圓弧參數放在既有物件窗格，使用共用座標、長度與角度組件；旋轉／翻轉視圖下保持圖稿座標語義。
- 貝塞爾控制點以所屬錨點為基準編輯偏移量；保留既有獨立入向／出向控制點，重合控制點共用編輯入口。
- 繪製起始手勢決定整條貝塞爾的放置方式：單擊起始採相對模式，依錨點／控制點交替放置；拖曳起始採絕對模式。後續不切換成混合模式。
- 同一錨點拖曳可建立對稱控制點；拖曳起始後的單擊錨點沿用上一段切線方向與控制偏移長度，維持銜接。
- 貝塞爾控制點及橢圓焦點提供相對／絕對參考模式，隨物件保存；切換模式保持幾何形狀，相對模式的參考連線顯示方向箭頭。
- 物件參數分組由「尺寸」改稱「形態」。新增圓／橢圓、折綫／貝塞爾轉換入口，依實際幾何判定能否保持形狀轉換；彎曲、回折等不符合條件的貝塞爾不直接轉為折綫。

## 圖層與印刷電路填充

- 美工層的基礎繪圖物件至少保留描邊或填充一項；兩者可同時啟用，入口改為各自前方的啟用複選框。
- 矢綫層不保存物件描邊與填充，始終顯示路徑與方向，仍可依實際幾何選取、拖曳。
- 印刷電路層的每個物件只能在描邊、填充之間擇一；同一圖層可同時容納描邊物件與填充物件，並共用該層唯一色彩，各圖層可使用不同顏色。
- 圖層規則接入繪製、屬性修改、跨層移動及匯入。圖層色票、預設填色與描邊色可歸檔及復原，美工圖層後方提供預設填色色票。
- 印刷電路閉合物件以同排三個圖形按鈕切換「描邊／實心／格綫」，開綫不顯示此模式列；填充模式隱藏一般描邊線寬。
- 依 AD 參考建立填充屬性 UI：實心的孤島面積、圓弧近似誤差、狹頸與規則選項；格綫的線寬、四個方向、X／Y 間距連動，以及最小圖元長度、鋪銅挖空、死銅與避空旋轉選項。
- 格綫方向可獨立啟用並自動換行，模式 SVG 隨方向同步；欄位順序為「線寬 → 格綫 → 間距」。
- X／Y 間距與連動按鈕改為共用整組組件，整組參與排版，不拆成不同列；輸入框依數值及本地化單位文字調整寬度。
- 移除暫時不採用的填充示意預覽、獨立填充標題列、焊盤圓弧／八邊形擬合及同網路覆蓋選項。
- 填充屬性支援存檔、復原、繪圖預設與新物件繼承；長度／面積接入共用計量模組，歸檔保留標準單位代碼與未修約量值。

## 路徑、吸附與選區

- 選取及靠近物件幾何邊界時顯示路徑提示，命中距離不完全依賴描邊寬度；無描邊的矢綫物件也可操作。
- 路徑方向按相鄰實際錨點分段標示，避免隨長度重複鋪設箭頭；端點離開視圖時仍於可見線段提示方向，不跨越不同子路徑的空隙。
- 一般矩形、圓、橢圓不假設預設路徑方向；矢綫層按其規則持續顯示方向。開放路徑同時標示起點與終點。
- 首個選區未實際參與合併時，不在背後重複繪製一般選區。
- 明確選取的重疊實際錨點可直接拖曳；格點、交點等隱含點不啟動實際錨點拖曳，自動吸附也不搶走直接命中的控制柄。
- 修正縮放後重用舊重疊候選位置的問題；依最新畫面探測位置重新判定吸附，清除的提示不會因重繪復活。
- 名稱統一為「靜態三角板」。操作中的三角板起點與游標尺點不提供靜態吸附參考；動態量測位置吸附到其他物件的開關仍獨立保留。

## 共用 UI 與效能

- 視圖、圖層、物件窗格統一接入同一個 ChipUI.floatingPanel，移除物件窗格獨立的拖曳與邊界實作，共用標題列、內容區、縮放、鍵盤及視窗邊界處理。
- 將窗格約定寫入 AGENTS.md：未經使用者明確指定，不新增另一窗格類型；缺少能力時擴充既有共用組件。
- 窗格拖曳改為起始時記錄尺寸、每幀更新位移、放開後提交位置；移動期間暫停背景模糊並簡化陰影。測試中的 300 次移動，拖曳階段窗格／頁首尺寸讀取由 600 次降為 0。
- 路徑提示重用既有節點及幾何取樣，懸停使用空間索引；視圖平移不重建未變更的設定控件。
- 過密的斜向虛綫按畫面像素抽稀顯示，保留設定值與吸附間距；一般密度的幾何不變。格綫背景未變更時直接重用，滿視圖格綫不再讀取無關物件邊界。
- 密集斜虛綫測試場景的單次重繪約由 16 ms 降至 11 ms；此為本機量測，實際表現依裝置與場景而異。
- 共用浮層在外部點擊時收起；整合原生與自訂圖示提示，避免同時顯示兩份 tooltip。
- 圖層選項綁定圖層色彩，以高對比文字、明確勾選標記及未選底色區分狀態；名稱與文字選項按鈕縮緊並對齊控制列。
- 錨點「詳細色彩」保留分組框，框線標題可展開／摺疊，預設收起，仍隸屬錨點分類。
