# 繪圖工具的交互模式與 SVG 提示

工具提示使用共用 `ChipUI.interactionHelp`，重用 SVG 節點與播放時鐘；隱藏或離開頁面時停止。矩形、圓弧與其餘繪圖工具沿用同一提示及選項模型，不另建窗格。

其他工具的手勢模式登錄在 `ChipUI.objectTypes[].interactions`。主工具提示依序展示各手勢模式，標出模式名稱、滑鼠按住／放開、定點、控制柄及完成方式；空心點為尚未確認，黃色游標代表按住滑鼠。

| 工具 | 交互方式 | 繪製模式與完成後行為 |
|---|---|---|
| 點 | 單擊 | 每次單擊放置一點，可連續放點，保留點工具 |
| 點 | 拖曳 | 在放開位置建立一點，返回預設工具 |
| 直線 | 點擊起點與終點 | 完成一條直線，保留直線工具 |
| 直線 | 按住起點拖到終點 | 放開完成，返回預設工具 |
| 圓 | 點擊圓心，再點擊半徑位置 | 完成後保留圓工具 |
| 圓 | 從圓心拖出半徑 | 放開完成，返回預設工具 |
| 橢圓 | 點擊中心，再點擊半軸位置 | 完成後保留橢圓工具 |
| 橢圓 | 從中心拖出兩個半軸 | 放開完成，返回預設工具 |
| 折線 | 逐點單擊 | 動態預覽下一段，雙擊結束；保留折線工具 |
| 貝塞爾 | 首次單擊 | 相對模式，交替點選錨點與控制點，雙擊結束 |
| 貝塞爾 | 首次拖曳 | 絕對模式，拖出對稱控制柄，後續錨點延續模式，雙擊結束 |

貝塞爾模式由第一次手勢決定。相對模式中後續拖曳、絕對模式中後續單擊均不會切換模式。動畫使用與畫布相同的錨點／控制柄狀態轉移、曲線路徑、預覽及相對參考箭頭，避免另一套近似示範。

## 驗證

`tests/tool-help.browser.mjs` 以真實滑鼠按下、移動、放開及雙擊回放六種工具的十一個模式，共 188 個取樣階段，核對原生 SVG 的預覽／完成圖形、控制柄、參考箭頭、橢圓焦點、相對／絕對模式、完成後工具狀態。另驗證後續手勢不改變貝塞爾模式、提示自動輪播模式、節點重用、連續更新及隱藏後停止。

既有矩形與圓弧的十九種方式仍由 `tests/construction-help-audit.browser.mjs` 進行 304 階段回放。瀏覽器測試以 `CHIPDRAW_PLAYWRIGHT`、`CHIPDRAW_BROWSER` 指定環境。

新工具的四階段截圖及核對結果預設寫入 `.codex-attachments/test-recordings/2026-11-09/other-tool-audit/`。可用 `node tools/record-construction.mjs <輸出.mp4> --help-only --other-tools` 錄製全部新工具提示，讓不同手勢模式依序自然播放。

操作示範共用單／雙擊與按住／放開事件標記；滑鼠及數位筆圖案指出所用按鍵，觸控標明輕觸次數。單步裁減為 2.4 秒，基本工具每模式 4.6 秒，不再長時間停留而沒有操作回饋。
