# 2026-11-08 變更整理

## JSON 模型與編輯

- 依 issue #54 建立獨立於 SVG 的共用物件模型、身份、驗證、幾何求解、隱式繼承、圖層資料及問題分類；SVG 作為畫布投影，不直接照搬 tag／attributes。
- 數值欄位使用 JSON number；物件面板單選直接顯示物件，多選才以 items 列出，不重複展示單位等前置上下文。未選物件時展示目前圖層模型。
- 「JSON 模型」置於物件面板底部，展開後同步選取及屬性修改。以單一 SVG 保存按鈕套用編輯，失敗時按鈕轉紅；移除正常狀態的說明及成功提示。
- 接入離線 Monaco 編輯器，包含 JSON 高亮、結構診斷、數值型別檢查、編輯器內撤銷及搜尋；內嵌工作執行緒可從離線 HTML 使用。
- 無解定義保留原始資料，透過問題清單與畫布標記繼續編輯，不把錯誤模型悄悄改寫成另一種幾何。
- 共用 JSON 資料邊界及記憶體文件管理核心拒絕循環引用與非有限數值。本次沒有接入 JSON 檔案保存／讀檔。

## 描邊與屬性排版

- 描邊與填充分開，以分隔線組織；線寬置於線型之後，移除額外巢狀分組框。
- 端頭提供 butt／round／square，接角提供 miter／round／bevel，以較清楚的 SVG 圖形按鈕呈現。
- 加入實線／虛線切換與實長、空長、偏移；實線隱藏虛線參數，正常參數不持續展示提示。
- 修正共用座標及計量控制項排版，維持數值與單位相鄰，不另建功能專用輸入規則。

## 共用窗格與工具列

- 視圖、物件與圖層面板目前預設展開並分開排列，方便同時觀察。
- 面板標題文字左側顯示各自圖示；收縮後使用相同圖示的共用工具列按鈕，點擊恢復。
- 繪圖工具列、收縮面板及按鈕扇出使用同一份 floatingPanel 工具列實作，共用把手、拖曳、鍵盤操作、邊界及四邊貼靠預覽與方向切換。
- 工具按鈕可拖出為獨立小工具列，保留原有按鈕動作與選取模型，可移動、貼靠、取消及返回。
- 未釘選面板由按鈕重新展開後，失去外部指標／鍵盤／視窗焦點立即收縮；重新釘選後保持展開。所屬選單、計量、色彩及編輯器操作不誤觸收縮。
- AGENTS.md 補充禁止另建窗格類型及工具列交互必須一致的約定。

## 矩形與圓弧繪製

- 矩形提供九個固定參考點及兩種對角點，共十一種模式；在旋轉／翻轉視圖下保持模型語義，尺寸編輯固定指定參考點。對角點模式只保存定義點，不重複保存推導寬高。
- 圓弧提供圓心與兩點、圓心／起點／掃角、三點、兩端點／半徑、兩端點／弓高、起點／切向／終點、雙切點／兩個切線角、圓心／半徑／起始角／掃角，共八種模式。
- 使用共用物件類型登錄表及選項模型提供 SVG 畫法按鈕；半徑、弓高及角度在既有物件面板以共用計量組件輸入。
- 支援帶正負號掃角、半徑圓弧選解、整圓及弦／扇形閉合。預覽不分配物件身份，完成建立單步撤銷紀錄，無解草稿不建立物件。
- JSON 往返及旋轉後的圓弧編輯保留原始定義方式，原有端點、座標、吸附及取消操作持續可用。
