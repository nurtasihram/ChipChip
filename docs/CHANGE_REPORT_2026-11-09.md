## 畫布內繪製

- 移除圓弧繪製時在物件屬性面板指定參數的欄位、完成按鈕及自動開啟面板流程。
- 八種圓弧均由畫布上的定點與游標動作完成；半徑、弓高、切向及帶方向的掃角即時決定，支援預覽、點擊／Enter 完成及 Esc 取消。

## SVG 交互提示

- 矩形、圓弧主按鈕及其所有繪製方式，在共用提示文字下方加入 SVG 操作動畫；沿用既有選項模型及提示組件。
- 動畫由每秒約六格的離散場景切換，改為隨畫面刷新連續更新並重用固定節點；提示關閉或頁面隱藏時停止更新。
- 編號與游標同步，空心表示尚未確認，點擊後才轉為實心；點擊位置與游標一致，完成後停留展示再重播。
- 動畫與實際畫布共用圓弧輔助線定義，修正第二點確認時機、雙切點切向線及半徑等提示差異。
- 弓高示例先移至弦中點，再沿法線調整；圓心類大弧完整留在提示區內，輔助線不覆蓋步驟文字。
- AGENTS.md 記錄強制規則：畫布動態繪製不得要求切換屬性面板；交互式繪圖工具須提供 SVG 動畫，逐方式核對其操作次序。
