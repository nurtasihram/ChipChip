# 2026-11-05 變更整理

### 繪圖與幾何

- 折線後新增貝塞爾曲線工具，支援逐點放置錨點、拖曳控制柄、完成／取消及單步撤銷。
- 折線與貝塞爾以次鍵完成已確認部分；Esc 取消未完成操作。
- 自由曲線暫緩，筆刷控制 API 與後續整合追蹤於 [GitHub TODO #52](https://github.com/nurtasihram/ChipChip/issues/52)。
- 圓與橢圓共用中心、半徑、長短軸及焦距模型；尺寸修改保持中心，避免把長寬數值當成拉伸量而改變線寬。
- 橢圓焦點可直接編輯、獨立選取與拖曳，遵守焦點鎖定；空心橢圓內部懸停顯示焦點，放大命中範圍並保留抓取偏移。
- 曲線控制點與節點以虛線連接；詳細錨點依懸停與操作狀態顯示。
- 視圖旋轉後，新建矩形／橢圓依當前畫面水平與垂直放置。

### 測量與視圖

- 繪製錨點、控制柄及移動操作統一顯示三角板；距離、ΔX、ΔY、座標與內角依共用計量設定顯示。
- 三角板長度與座標排在外側，角度標於頂點，直角使用折線符號；共線及零位移省略重複標示。
- 移除圓的重複半徑提示，縮短圓／橢圓的繪製資訊。
- 選區、錨點、吸附提示與測量尺共用圖稿座標系，跟隨平移、縮放、旋轉及鏡射；淡出中的選區同樣跟隨視圖。
- 操作中變更視圖時重投影尺點；移動對象被刪除即結束操作。
- 修正扇出選區的描邊邊界，分離首個與一般選區的繪製樣式與聯合計算設定。

### 吸附與效能

- 最近探測使用空間索引與有界格點查詢；附近所有的有限展示量只查找所需近鄰，避免先枚舉整個密集格線區域。
- 移除設定中的「附近候選」下拉行；保留畫布上的重疊候選清單與立即切換。
- 吸附與選取共用錨點類型控件；依情境決定是否列出角點、中點、交點、格點等隱含點。
- 「靜態測量尺」僅提供固定參考幾何作為目標；「測量尺動態吸附」分別控制縮旋尺與三角板是否跟隨吸附點。
- 「詳細色彩」保存各類錨點顏色，候選清單與畫布標記一致；鎖定候選在名稱前顯示鎖圖示。
- 重用移動時的選區幾何及縮放取樣，貝塞爾控制柄使用自適應取樣並合併每幀更新；拖曳期間不反覆重建屬性表。

### 選取與操作回饋

- 新增選取頁，物件類型與錨點類型並列，可同時勾選；圖層篩選與吸附共用同一圖層選項組件。
- 實際錨點依可編輯座標點分類，包含端點、節點、控制點、圓心／中心、焦點及位置點；錨點可在所屬物件未選取時獨立操作。
- 新增重選、增選、消選，以及內含／外包範圍計算；增選、消選未命中時仍提示選空。
- 重選／增選／消選改為圖形單選按鈕，經分隔線後以單一兩態圖形按鈕切換內含／外包。
- 拖動切換抓取光標；鎖定焦點、節點及物件阻止拖動並提示，遵守選取篩選與鎖定規則。

### 共用介面

- 選色沿用原有入口，使用 HSV 色彩平面與彩虹色相條；動態色彩欄位共用相同流程，保留色碼格式輸入及取消還原。
- 選色標題列緊湊化；下拉清單置於最上層，避免被面板遮擋。
- 下拉選項以鍵盤或滾輪移動時立即套用；未展開時只切換值，不自動彈出清單。
- 補齊共用圖示、圖層選項、情境錨點選項及兩態按鈕模型。
- 重建 ChipDraw、ChipChip 及入口離線 HTML，新增並擴充幾何、測量、吸附效能與互動回歸測試。
